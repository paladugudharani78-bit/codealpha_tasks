# CodeAlpha Hangman Game

## Project Description

This is a simple text-based Hangman Game developed using Python as part of the CodeAlpha Python Programming Internship.

The game randomly selects one word from a list of five predefined words. The player must guess the word one letter at a time.

## Features

* 5 predefined words
* Random word selection
* Letter-by-letter guessing
* Maximum 6 incorrect guesses
* Detection of repeated letters
* Console-based interface
* Win and Game Over messages

## Technologies Used

* Python
* Random module
* Lists
* Strings
* While loop
* If-else conditions
* User input

## How to Run

Open the terminal in the project folder and run:

```bash
python hangman.py
```
