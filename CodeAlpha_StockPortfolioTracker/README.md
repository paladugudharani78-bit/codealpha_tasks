# CodeAlpha Stock Portfolio Tracker

## Project Description

This project is a simple Stock Portfolio Tracker developed using Python as part of the CodeAlpha Python Programming Internship.

The program uses predefined stock prices and allows the user to enter stock names and quantities. It calculates the investment value for each stock and the total investment.

## Features

* Hardcoded stock prices
* User input for stock names
* User input for quantities
* Investment calculation
* Total investment calculation
* Portfolio summary
* Saves the result to a text file

## Technologies Used

* Python
* Dictionary
* Lists
* Loops
* Conditional statements
* Basic arithmetic
* File handling

## How to Run

Open the terminal in the project folder and run:

```text
python portfolio.py
```

Enter the stock name and quantity when prompted.

Type `done` when you have finished entering stocks.
