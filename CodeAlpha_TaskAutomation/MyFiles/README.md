# CodeAlpha Task Automation

## Project Description

This project is a Python automation script developed as part of the CodeAlpha Python Programming Internship.

The script automatically finds all JPG files in a specified folder and moves them into a separate `JPG_Files` folder.

## Features

* Automatically finds JPG files
* Creates a destination folder
* Moves JPG files automatically
* Reduces repetitive manual file organization

## Technologies Used

* Python
* os module
* shutil module
* File handling
* Loops
* Conditional statements

## How to Run

1. Create a folder named `MyFiles`.
2. Place JPG files inside the folder.
3. Open the project in VS Code.
4. Open the terminal.
5. Run:

```text
python file_organizer.py
```

6. The JPG files will be moved into the `JPG_Files` folder.
